# Today plans

> `/routine today-prep` writes one file here each morning, `YYYY-MM-DD.md`. It starts from
> last night's `tomorrow-plans/` file when there is one, and fills gaps from the vault.

Shape of a file:

```markdown
## Today Prep - {YYYY-MM-DD}

> Source: tomorrow-plans / vault scan / both

### Work
1. {most important work item} (planned)
2. {second option}
3. {third option}

### Personal
1. {most important personal item} (planned)
2. {second option}
3. {third option}
```

`(planned)` marks an item that came from the evening plan.
