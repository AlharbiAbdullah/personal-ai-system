# Journal

> Occasional, trigger-based reflection. `/routine journal` asks one question and writes your
> answer here. It is not a daily obligation: write when you made a decision, changed your
> mind, hit a pattern for the third time, or feel off and don't know why.

One file per entry, `YYYY-MM-DD.md`, in this shape:

```markdown
---
date: {YYYY-MM-DD}
time: {HH:MM}
type: journal
---

{One to three paragraphs of prose, in your own words. No headers, no bullets.}
```
